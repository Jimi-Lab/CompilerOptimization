## Paper-Ready Narrative

Phasar IFDS-uninit reports use 32 in the O2-g zfp run as an uninitialized use of `s` in `encode_ints_uint32.29`, file `src/template/encode.c`, line 244, with source text `if (++s->bits == wsize) {`. The reported file/line pair is syntactically valid, but semantically inconsistent: `src/template/encode.c:244` is `if (size <= 64)`. The reported source text recovers exactly to `include/zfp/bitstream.inl:244`, inside the inline helper `stream_write_bit`.

The O2-g IR anchor in the disassembled artifact is `%256 = add i64 %250, 1` in `encode_ints_uint32.29`. Its debug location is `!7903 = !DILocation(line: 244, column: 7, scope: !7766, inlinedAt: !7899)`. The scope `!7766` belongs to `stream_write_bit`, whose file is `Target/zfp/include/zfp/bitstream.inl`. The inline chain then points to `encode.c:198`, the call `stream_write_bit(&s, !!x)`, and further to `encode.c:252`, where `encode_few_ints_prec_uint32` is inlined into `encode_ints_uint32.29`.

The drift is therefore not that the instruction lacks a usable source location. Rather, Phasar's report combines fields from different debug metadata sources. The line and source text come from the instruction's `DILocation` in `bitstream.inl`, while the file is pulled toward `encode.c` because `%256` is immediately used by an `llvm.dbg.value` as a fragment of local variable `s` (`!7836`) declared in `encode_few_ints_prec_uint32` at `encode.c:183`. This matches the known Phasar `getFilePathFromIR` behavior: when an instruction is used by debug metadata, it prefers the associated `DILocalVariable` file over the instruction's own debug file.

This is a high-confidence `FP-LocationDrift` / source-mapping failure case triggered by optimized inline debug metadata. It should be used as evidence that O2-g IR can expose report-layer fragility in IR tools, not as a source-level uninitialized-use judgment. No local O0 or O2-noinline Phasar zfp run was found under `CompilerOptimization/Result/zfp/phasar`, so this case is not yet a cross-universe inline-ablation result.
